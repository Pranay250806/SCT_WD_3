# Quiz Game Application

An interactive and responsive Quiz Game Application developed using HTML, CSS, and JavaScript.

## Features

- Multiple-choice quiz questions
- 10 quiz questions
- Displays four answer options
- Highlights correct and incorrect answers
- Prevents selecting multiple answers
- Next question button
- Progress indicator
- Score calculation
- Final score display
- Restart quiz option
- Responsive design for desktop and mobile devices
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
